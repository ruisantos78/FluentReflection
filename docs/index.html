FluentReflection.NET

An expressive, fluent reflection API for .NET 10 that exposes private, internal, and public members (fields, backing fields, properties, methods, and events) to make unit testing easier — no internal constructors or [InternalsVisibleTo] required.

Install from NuGet

Package: FluentReflection.NET

dotnet add package FluentReflection.NET

Package Manager Console

Install-Package FluentReflection.NET

Types

Quick Example

using FluentReflection;

var name   = Class.Of(obj).Property("Name").Get<string>();
var count  = Class.Of(obj).Field("_count").Get<int>();
var result = Class.Of(obj).Method("HiddenMethod").Invoke<string>("arg");
var subs   = Class.Of(obj).Event("Changed").GetInvocationList();
