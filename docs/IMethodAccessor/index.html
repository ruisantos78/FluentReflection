IMethodAccessor Class

public interface IMethodAccessor

Namespace: FluentReflection.Accessors · Assembly: FluentReflection.NET

Remarks

Fluent accessor for invoking synchronous and asynchronous methods. Obtained via IClass.Method(string). When a method name has overloads, the accessor automatically picks the overload whose parameter count and types best match the supplied arguments.

Note: although the public contract is the interface below, the concrete implementation (MethodAccessor) is internal. Access it only through the fluent API.
