public static class Class

Namespace: FluentReflection · Assembly: FluentReflection.NET

Remarks

Static factory class providing all entry points to FluentReflection.NET. Use Class.Of(...) to create a fluent wrapper over a concrete instance or a static type, and Class.From(...) to resolve a type dynamically by name across loaded assemblies. All factory methods return an IClass wrapper that exposes fluent member accessors.
