ObjectExtensions Class

public static class ObjectExtensions

Namespace: FluentReflection.Extensions · Assembly: FluentReflection.NET

Remarks

Fluent extension methods for objects, types, and assemblies that provide shorthand access to the Class factory, enabling a more conversational, chainable API such as instance.AsClass().Property("Name").Get().
