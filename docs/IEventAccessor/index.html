IEventAccessor Class

public interface IEventAccessor

Namespace: FluentReflection.Accessors · Assembly: FluentReflection.NET

Remarks

Fluent accessor for interacting with events and their subscribers. Obtained via IClass.Event(string). Use it to introspect which delegates are subscribed to a (potentially private) event without invoking it.

The accessor locates the backing delegate field using several naming conventions, and walks the base-type hierarchy to support inherited events. Note: although the public contract is the interface below, the concrete implementation (EventAccessor) is internal; access it only through the fluent API.
