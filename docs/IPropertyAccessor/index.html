IPropertyAccessor Class

public interface IPropertyAccessor

Namespace: FluentReflection.Accessors · Assembly: FluentReflection.NET

Remarks

Fluent accessor for reading and writing property values. Obtained via IClass.Property(string). Supports reading and writing both exposed properties and their underlying backing fields, as well as read-only and otherwise inaccessible private setters.

Note: although the public contract is the interface below, the concrete implementation (PropertyAccessor) is internal. Access it only through the fluent API.
