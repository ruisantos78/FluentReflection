IFieldAccessor Class

public interface IFieldAccessor

Namespace: FluentReflection.Accessors · Assembly: FluentReflection.NET

Remarks

Fluent accessor for reading and writing field values. Obtained via IClass.Field(string). It resolves named fields directly and also supports compiler-generated backing fields (<Name>k__BackingField), for both instance and static scopes.

Note: although the public contract is the interface below, the concrete implementation (FieldAccessor) is internal. Access it only through the fluent API.
