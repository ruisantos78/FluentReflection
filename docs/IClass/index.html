IClass Class

public interface IClass

Namespace: FluentReflection · Assembly: FluentReflection.NET

Remarks

Fluent interface for interacting with members of a class or instance using reflection. Every entry point returned by the Class factory or ObjectExtensions exposes this contract. It provides direct member access (Get/Set), method invocation (Invoke), and dedicated accessors for properties, fields, methods, and events.

Member resolution automatically handles private, internal, public, and compiler-generated backing fields (<Name>k__BackingField), for both instance and static scopes.
